# 文献依据（治"agent 自作主张处置建模问题"）

## 这条规则解决什么

Agent 在建模时遇到的每一个分岔口——缺失值怎么填、不平衡怎么处理、阈值怎么定、用哪个模型、
调参用单折还是多折——都会**默认自行决定**。它的决定通常看起来合理，讲得出道理，还会附上一段
机制解释。于是人看到的是"已经做完了"，而实际发生的是：**一堆没有人做过、也没有文献支持过的
选择，被静默地做掉了**，然后以"实验结果"的形式回到人面前。

这类决定有三种，只有第一种是安全的：

| 类型 | 例子 | 风险 |
|---|---|---|
| **有文献依据** | "CLIMB 说单折验证会因少数类稀缺而过拟合，改用多折" | 低——可追溯、可质疑 |
| **有同构机制可借** | "本问题正样本绝对稀少（机制 A），邻居问题有关于机制 A 的证据" | 中——必须写明边界并本地验证 |
| **无来源的临场决定** | "正样本权重设成 2.75"；"缺失用均值填" | **高——这是本条规则要拦的东西** |

第三种决定的危害不是"可能错"。是它**无法被审计**：事后没人能说清这个数字是哪来的，
于是它既不能被推翻，也不能被改进，只能一直待在那里。人"对数据没有感觉"的一部分原因，
正是这类决定太多——每一步都有一处"不知道从哪来的选择"。

## 规则（硬性）

**任何建模决定，在写进协议块之前，必须先落到下面三档之一，并在协议块里写出档位与依据。**

### 第 1 档：有文献依据 → 直接引用

要求全部满足：
- 引到**具体位置**（论文、节号/表号、原句），不引摘要；
- 文献的**实测范围**覆盖本问题的关键特征（见下"范围戳"）；
- 若有数字，写出数字与出处。

### 第 2 档：有同构机制可借 → 必须三件事齐全

1. **指名机制**，并说明本问题确实存在该机制（不是"听起来像"）；
2. **写明边界**：文献在哪里停住，我从哪里开始外推；
3. **本地验证**：把这个外推变成一个**可证伪的预测**写进协议块的成功/失败判据，
   允许它被证伪。

> ⚠️ 只写 1、2 不写 3 = 用文献给自己的猜测镀金。这是比第 3 档更坏的情况，
> 因为它表面上"有依据"。

### 第 3 档：无文献支持 → ⛔ 停下来告诉人，不许自行决定

**先分两小类** —— 不是所有第 3 档都要占用人的决策带宽：

| 小类 | 判据 | 动作 |
|---|---|---|
| **可扫的参数** | 该决定能被一个参数网格覆盖（阈值、比例、融合形式、窗口长度、容差…） | **不问人**，直接做**敏感性扫描**，并在结论里写"在 X 范围内成立 / 不成立" |
| **不可扫的选择** | 无法用参数网格覆盖（是否要做这件事、用哪份数据、要不要换课题） | 才需要按下表汇报并停下等人 |

> **为什么这样分**：一个可扫的参数，"你想取哪个值"远不如"换值会不会改变结论"有用。
> 实测收益（本仓库）：对两项第 3 档决定做扫描，不仅回答了"选择重要吗"，
> 还**推翻了一条已入账的结论**（原写"方向稳定为正"，而逐折中位在 4/5 个设置下为负）。
> ⇒ **能扫的决定不该占用人的决策带宽。**

**不可扫时才做的事**：不许"先用一个合理默认值跑一版看看"、不许把决定藏在代码里、
不许在摘要卡里只汇报结果不提这个决定。把下面五件事讲给人听（用平实的话，不要造词），然后停下等人回答。

| 要讲什么 | 说明 |
|---|---|
| **这是什么选择** | 一句话，人话。例："缺失值用什么方式补" |
| **为什么必须选** | 不选的后果。例："不补就没法喂给模型，这一步绕不过去" |
| **这个问题的特征** | **本问题实测的数字**，不是形容词。例："缺失率 57%，且是整台设备全空，不是随机撒点" |
| **现有文献覆盖到哪** | 诚实说明查过什么、边界在哪。例："CLIMB 测过 30% 随机缺失 + 均值填充，但它的数据集全部排除时序、全部排除缺失值场景，且它自己把'缺失与不平衡的组合效应'列为 future work" |
| **需要什么调研** | 缺口类型。例："需要找工业时序设备停机式缺失的处理文献，不是表格缺失文献" |

**汇报的判据**：人听完之后，能自己判断"这个问题是难是易、值不值得投入"。
做不到就说明"这个问题的特征"那一栏写的是形容词而不是数字。

### 三档都要附的"范围戳"

每条文献依据都要回答一句话：**这篇论文自己声明的适用范围是什么，它实际测了什么。**

两者经常不一致，而**不一致处正是误用的高发区**。典型形态：

- 论文声明"表格不平衡学习"，实测范围是"决策树基学习器 + i.i.d. + 无缺失 + 非时序"；
- 论文声明"不确定性的价值"，实测是在 i.i.d. 随机划分上而非真正的分布偏移上；
- 论文的结论是**平均意义**上的（跨 N 个数据集平均），而我要用的是**单个个例**。

格式：`声明范围 | 实测范围 | 因此不能用来支持什么`。

### 绝不做的四件事

1. **不读摘要就引用。** 摘要里的增益经常只在很窄的设定下成立（尤其贝叶斯类论文）。
2. **不把单次运行的增益当证据。** 没有多种子/重复/置信区间的改进，写 `原文未报告`。
3. **不把"我的指标"假定成"它的指标"。** 指标不同则排名不可借；只能借**机制解释**，
   并且那个机制要本地验证。
4. **不因为"我的问题更极端"就外推文献结论。** 更极端的区间是**没有证据**的区间，不是
   "结论仍成立"的区间。

## 两类"少"必须分开（最常被混为一谈）

| | 类别占比不平衡 | 正样本绝对稀少 |
|---|---|---|
| 形态 | 少数类占比低，但**数量足够**（几百~几万） | 少数类**本身就少**（个位数 ~ 几十） |
| 常规对策 | 重采样、重加权、代价敏感 | 这些**没有作用对象**（无法在 1 个样本的邻域插值、无法做近邻清洗） |
| 文献可迁移性 | 高（大多数不平衡文献属于此类） | 低（这类问题通常叫少样本/极端稀有事件） |

**本实例同时具备两者，且必须分尺度陈述：**

- **事件级**：全训练集 11 个故障事件、8 台设备 → 每台设备最多 1~2 个 → **这是"绝对稀少"**，
  决定了统计功效与跨设备泛化能力（LODO 每折只留出 1~2 个事件）。
- **窗口级**：每个事件在 96 h 特征窗口内约有 288 个可用正样本落点（11 × 288 ≈ 3168 个正窗口）
  → **这是"占比不平衡"**，决定了训练是否欠拟合。

**把这两件事说成一件，是所有不平衡文献误用的总源头。** 谈跨设备泛化时用事件级；
谈训练充分性时用窗口级；任何"因为不平衡比是 X 所以应该做 Y"的句子，先问它用的是哪个尺度。

## 合成实验的事前自检（三次实测失败换来的）

用合成数据检验一条判据时，**合成场景本身可能让结论必然成立或必然不成立**，
于是跑出来的"发现"是假象。这不是理论错误，是**实验设计错误**，而且它极难自查 ——
因为脚本正常结束、数字正常打印、结论读起来也合理。

### 两次实测失败（同一类错的两个形态）

| 失败 | 形态 | 表现 |
|---|---|---|
| 合成场景**没复现实测结构** | 生成过程与真实数据的机制不同 | 实测 `corr(σ²,μ)` = **+0.60**，合成里造出 **−0.19**（符号相反）；模型本身已收敛（`AUC(μ)`=0.831 对理论上限 0.832） |
| 合成场景**让条件恒真/恒不可满足** | ①"预测"恒真 ⇒ 无区分力；②某个被测条件在生成过程中不可能发生 | 384 格里只有 32 格一致（预测几乎恒真）；"块内混合"**恒为 0**（因为块标签在生成时是确定的）⇒ "三条件"几乎恒假 |

### 事先必须做的四项自检（缺一项就可能重犯）

**⓪ 网格设计检查：判据的**两侧**都必须可达。**
若"预测"在网格里恒真，则检验**必要性**的格子一个都没有 —— 跑出来的"无反例"是**设计的产物**。
> 实测：某次扫描取 `N ≥ 3`，于是"保留层级 ≥ 2"恒真；非退化自检报出
> **预测成立比例 = 864/864 = 1.000** 才暴露。**修法：把 `N = 1` 这类退化取值也放进网格。**

**① 复现结构检查。** 合成生成过程是否复现了真实数据的**关键结构**？
不是"看起来像"，而是逐条对照：块的定义、标签在块内是否可变、依赖哪几个维度。
> 例：真实数据里"块 = 落在某个 24h 簇内的那批窗口"，**窗口结束时刻不同 ⇒ 标签会混合**；
> 若合成里"块 = (单元,簇)"且标签确定，则**结构就没复现**。

**② 非退化检查（两个方向都要）。** 在跑主分析之前，先单独统计：
- **每个被测条件实际成立的比例** —— 若某条件成立率 ≈ 0% 或 ≈ 100%，它在该场景里**没有信息**；
- **"预测"的分布** —— 若预测恒真或恒假，它**没有区分力**，一致率会虚高。

**③ 冒烟对照检查。** 先在**已知答案**的场景上跑一次：
若判据在"应当成立"和"应当不成立"两种场景上给出同一种结果，则判据或场景有一方是坏的。

**④ 双向反例搜索。** 把判据拆成两条独立命题分别找反例，不要只报"一致率"：
- **必要性**（结论 ⇒ 条件）：找"结论成立却不满足条件"的格子；
- **充分性**（条件 ⇒ 结论）：找"满足条件却不成立结论"的格子。
> 只报一个方向的一致率会掩盖"条件不充分"这一半事实。

**⑤ 结构与噪声的区别检查（最隐蔽的一条）。**
若生成器允许"随机翻转标签"来制造变异，那么"变异"里就**混入了噪声**。
此时任何"存在变异就算有信息"的条件都会**把噪声误判成信息**。
> 实测：某扫描用 `p_within` 随机翻转标签，于是"块内混合 > 0"在**时间维度只剩 1 层**的格子里
> 也能成立 ⇒ 出现 118 个反例，而根因不是被检验的原则错，是**"信息量"的操作化错**。
> **修法**：区分"结构变异"（由独立单元/簇产生）与"噪声变异"（块内随机）。
> **判据**：报告里必须能说清"这个变异是从哪来的"。说不清 ⇒ 结论不可采信。

### 顺序也很重要

**先用实测数据解剖机制，再据此设计合成场景。** 反过来做（先造场景再看结论）
必然造出与实测结构不符的场景 —— 两次失败都是这个顺序。

**判据**：合成实验的报告里，**必须能看到上面四项的结果**。
看不到 ⇒ 该实验的结论不可采信，不管它看起来多合理。

## 处理建模问题时的工作顺序

1. **先查有没有文献**（本课题的文献目录 + 相关领域）。查到了 → 走第 1/2 档。
2. **查不到 → 先别动手**，按上面五栏向人汇报，说明需要什么调研。
3. **人决定之后**，才写进协议块，并在协议块的"依据"字段标注档位与来源。
4. **结果出来后**，回填：这个依据**被支持还是被证伪**。被证伪的依据要进冲突台账
   （`CONTRADICTIONS.md`）并更新本条。

> 反直觉但重要：**第 3 档的正确产出不是"一个决定"，而是"一个明确的待调研问题"。**
> 人的直觉倾向于"先跑起来再说"，但在这个项目里，一个无来源的决定产生的数据**不可用**——
> 因为没人知道该拿它跟什么比。

## 与其它机制的关系

| 机制 | 关系 |
|---|---|
| **协议块** `PROTOCOL-*` | 每个决定必须带"档位 + 依据"字段；第 3 档未获人回答 → 不许起草/批准 |
| **问题台账** `Q-*` | "本问题的特征"（缺失模式、标签不确定性、尺度分裂）属于问题台账；它们是第 3 档汇报的原料 |
| **方法台账** `M-*` | 第 1/2 档被本地证伪后，沉淀为方法台账条目（适用边界由此具体化） |
| **冲突台账** `CONTRADICTIONS.md` | "文献说 A，我本地测出非 A"必须入册，不许静默覆盖 |
| **理论台账** `T-*` | 当"文献的 future work 恰好是我的问题特征"时，这是最强的理论入账信号 |
| **摘要卡** | 若本轮含第 3 档决定，摘要卡必须有一行说明它，不许只报结果 |

## 一条配套的自检（可机械执行）

写完协议块后，对块内**每一个会影响结果的参数或选择**，问一句：

> **"如果换一个值，结果会变吗？"** 会变 → 它就是一个建模决定 → 必须有档位与依据。
> 答不出"这个值是哪来的" → 它是第 3 档，必须先问人。

常见的、最容易漏检的隐性决定清单（每次都要过一遍）：

- 缺失值填充方式（均值/前向/丢弃/不填+掩码）
- 正负样本权重、任何重采样比例
- 预测视野长度、特征窗口长度、滑动步长
- 正负样本的标注容差（事件时刻与网格对齐的容差）
- 负样本排除带（距事件多远算"必须排除"）
- 验证切分方式（随机 / 按设备 / 按时间）
- 阈值选择方法（在校验集选 / 固定分位数 / 按公式）
- 模型数量、训练轮数、早停判据
- 评价指标的实现口径（Recall/FPR 的分子分母怎么数）
