## 块号
`P-BOILER-001`

## 一句话主张
11 个故障事件前 96h 内，至少一个传感器通道存在可检出的趋势漂移，其判别力在事件级留一交叉验证下 AUC ≥ 0.70。

## 为什么是这一步
它决定后续所有建模路线的形状：若单通道漂移已可检出，主线就是"可解释的物理特征 + 阈值门控"；若不可检出，主线必须转向序列模型 + 不确定性，且必须引入外部先验。同时它测掉本课题最贵的前提——召回能不能做到。

## 既有证据
- `Q-1`（`稳定`）：测试切片每片恰好 1152 行 = 96h，5 分钟采样 → 前置窗口长度固定为 96h，无需自行选择
- `Q-2`（`稳定`）：故障事件仅 11 条，覆盖 7 台设备 → 事件级独立样本 n=11，任何 CV 必须按事件分组
- `Q-5`（`?`）：正类比例 P 未知 → 本块不依赖 P，主指标用 AUC 而非榜单分数
- 台账中没有任何一条涉及"前置信号是否存在" → 本块不是重测

## 主指标
事件级留一交叉验证（Leave-One-Event-Out, LOEO）下的 **ROC-AUC**：

```
对每个候选通道 c 与统计量 s（均值/斜率/方差），在事件前 96h 窗口与同设备同期负窗口上
分别计算 s，得到分数 → 按事件分组做 LOEO，把 11 折的样本外预测拼起来算 AUC。
AUC = P(正窗口分数 > 负窗口分数)
```

主指标只有一个：`AUC_LOEO`。其余通道统计量、单变量 t 检验 p 值只作记录，**不参与成败判定**。

## 最小可检测效应
- n=11 个事件时，单个事件的翻转对 AUC 的影响量级 ≈ 1/11 ≈ 0.09；
- LOEO 下 AUC 的 95% 区间宽度经验值约 ±0.12（11 折、正负样本不均衡）；
- 因此 **AUC < 0.70 与 AUC = 0.70 无法区分**，判据的下限必须是 `0.70 + 0.09 ≈ 0.79`，
  否则"通过"与"刚好没过"在统计上不可区分；
- 这条**直接约束下一节的成功判据**：成功判据必须 ≥ 最小可检测效应所要求的那个值。
  （本样张的初版就违反了自己这条规则，见文首修订痕迹。）
- 参考命令：
  `python scripts/score_noise_floor.py --n-test 510 --formula recall_exp_fpr --tau 0.05 --k 3 --pos 41 --enumerate`
  （该命令给出的是榜单噪声下界；本块用的是事件级 LOEO 的噪声，两者都在 `CHARTER.md` 中登记）

## 对照
**同设备、同为 96h、但远离任何故障 ≥14 天的窗口**（同长度的负窗口）。

实验组与对照组只差一处：窗口相对故障时刻的位置。其余（通道、统计量、窗口长度、设备）完全一致。

## 成功判据
存在至少一个通道，`AUC_LOEO ≥ 0.79`（= 0.70 + 1/11，即效应量至少跨过一个事件的
分辨率），**且**在 11 折中 ≥9 折方向一致（同一方向的漂移），**且**把贡献最多事件的
那台设备整体留出后 `AUC_LOEO` 仍 ≥ 0.70（排除"结论由单个设备驱动"）。

## 失败判据
所有通道 `AUC_LOEO < 0.70`，或方向一致的折数 ≤6（等价于接近随机）。

## 绝不能声称
- 不能声称"该通道可用于预警"——AUC 高不等于能在 τ 约束下达到目标召回；
- 不能声称"适用边界"——只在 7 台设备、11 个事件上验证；
- 不能声称"优于某方法"——本块没有对照方法，只有通道内对照；
- 不能声称"漂移是结垢导致的"——本块只测统计相关性，不做因果；
- 11 折中有 ≥2 折方向矛盾时，不得声称存在漂移（只能声称"部分事件存在"）。

## 停止规则
- 任一通道在 3 台以上设备上无法构造足够的负窗口（远离故障 ≥14 天的 96h 窗口 < 5 个）→ 停止，改为报告"负样本不足"并升级为新的堵点；
- 若前 3 个通道的 AUC 全部落在 [0.45, 0.55] → 停止单变量勘察，直接进入多变量路线（不继续扫其余通道）。

## 预期成本
- 1-epoch 基准：本块不训练模型，纯特征统计。预计单机 < 3 分钟，内存 < 2 GB；
- 数据：20 个 CSV 共约 88 MB，一次读入转 `.npz` 缓存（复用 `experiment-standards` 的缓存建议）；
